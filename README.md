# Solana OS

A Solana desktop that runs in the browser. The interface is in English.

## Run

```bash
cd apps/web
npm install
npm run dev
```

Open the printed local address. The first launch shows a short boot screen. Press Enter to skip it.

The desktop application hosts the browser as its own document, so sites are not framed. Start the dev server, then in another terminal:

```bash
cd apps/web
npm run desktop
```
